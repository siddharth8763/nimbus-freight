# Nimbus Freight — dashboard

React + TypeScript UI for the reefer alert API. Start the [backend](https://github.com/siddharth8763/nimbus-freight-backend) on port 8080 first.

## Run

```powershell
npm install
npm run dev
```

Open http://localhost:5173 and use **Replay seed data**. Vite proxies `/api` to `http://localhost:8080`.

## Build

```powershell
npm run build
```
